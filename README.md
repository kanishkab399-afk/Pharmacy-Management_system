# Pharmacy Management System

A simple Pharmacy Management System developed using Python, Streamlit, and SQLite.

## Features

- Add customer details
- Store customer name and phone number
- Store data using SQLite
- Generate reports
- Simple Streamlit interface

## Technologies Used

- Python
- Streamlit
- SQLite
- SQL
